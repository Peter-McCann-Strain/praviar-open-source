# Operations reference

These files preserve an unvalidated operating design for engineering study.
They are not a supported runbook, service-level commitment, deployment
approval, or evidence of a running environment.

- [`runbook.md`](runbook.md): local setup and diagnostic starting points.
- [`../deployment.md`](../deployment.md): local development and hosted topology
  reference.
- [`../limitations.md`](../limitations.md): security, deployment, data, and
  support boundaries that apply to every operating note.

Before adapting any command, independently review identity, tenant isolation,
networking, secrets, provider egress, data location, retention, monitoring,
backup, restore, incident response, costs, and third-party terms.
