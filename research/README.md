# Research

This tree is reserved for benchmarks, experiments, validation assets, and
research tooling. It is not part of the product runtime import surface.

The public archive contains selected project tooling, tests, documentation,
schemas, configuration, and synthetic fixtures only. Raw patent documents,
downloaded datasets, experiment outputs, validation corpora, and internal
readiness evidence are deliberately excluded because their licences, privacy
posture, or evidentiary status differ from the Apache-2.0 software.

Nothing in this directory grants rights to a dataset, patent document, provider
response, or model artefact. Use the included synthetic fixtures for local
inspection and review authoritative upstream terms before adding external data.
