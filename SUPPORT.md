# Support

This chemical patent-analysis system is a best-effort open-source research and
engineering project. It has no
service-level agreement, guaranteed response time, uptime commitment, or legal
support obligation.

- Use GitHub Issues for reproducible defects and documentation corrections.
- Follow `SECURITY.md` for suspected vulnerabilities; do not file them publicly.
- Report licensing or attribution concerns privately as a security-sensitive
  issue until the affected material can be reviewed.

Do not submit confidential compounds, patent strategy, customer data, secrets,
or privileged legal material in an issue or discussion.
